Basit ama etkili bir **WhatsApp Web otomasyon aracı**.  
İki farklı mod sunar:

- ✍️ **Yazıyor Modu:** Karşı tarafa sürekli “yazıyor...” olarak görünür.  
- 📩 **Spam Modu:** Belirli bir mesajı, belirlenen sayıda ve aralıkta gönderir.

---

## 🚀 Özellikler

- 🧠 `webdriver-manager` sayesinde **ChromeDriver otomatik kurulur**  
- 💬 Spam modunda **mesaj aralığı (saniye)** ayarlanabilir  
- 🌀 Rastgele yazı simülasyonu (doğal "yazıyor" efekti)  
- 🧍‍♂️ Etkileşimli terminal menüsü  
- 🛑 `Ctrl + C` ile güvenli durdurma  

---

## 🧩 Gereksinimler

- Python **3.8+**
- Google Chrome (veya Chromium)
- Aktif WhatsApp hesabı
- Windows/Linux Uyumlu.
