# whatsappw
Basit bir WhatsApp Web otomasyon aracı. QR kodla giriş yaptıktan sonra:  “Yazıyor” modu ile karşı tarafa sürekli yazıyor gibi görünür.  “Spam” modu ile belirlenen mesajı istenen sayıda ve aralıkta gönderir.  Selenium ve webdriver-manager kullanır, ChromeDriver’ı otomatik olarak yönetir.
